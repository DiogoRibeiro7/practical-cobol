# COBOL vs modern languages

COBOL feels different from Python, JavaScript, or Rust, but many ideas are familiar.

## Similar ideas

- variables
- conditions
- loops
- functions or reusable blocks
- input and output
- file processing

## Different emphasis

COBOL places a stronger emphasis on:

- explicit data layout
- record-oriented processing
- business-readable structure
- large batch-style workflows

## A useful mindset

Do not ask: "Why is COBOL not like Python?"

Instead ask: "What kind of problems was COBOL built to solve well?"

That question makes the language much easier to understand.
