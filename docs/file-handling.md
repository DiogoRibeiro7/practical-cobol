# File handling

One of the most important COBOL use cases is sequential record processing.

Typical steps:

1. define the file in the `ENVIRONMENT DIVISION`
2. describe the record structure in the `DATA DIVISION`
3. open the file
4. read one record at a time
5. process totals, flags, and reports
6. detect end of file
7. close the file

This repository introduces files only after the learner is comfortable with:

- variables
- conditions
- loops
- paragraphs

That keeps the learning curve manageable.
