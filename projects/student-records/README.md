# Student Records Report

This project is a guided next step rather than a finished capstone. It is a good follow-up after lessons 08 and 11 because it focuses on small record sets, averages, classification, and report output.

## Suggested objective

Build a program that:

- reads student names and grades
- computes class totals and average grade
- classifies each student as pass or fail
- prints a small summary report

## Best lessons to review first

- lesson 05 for conditions
- lesson 08 for tables and repeated records
- lesson 11 for report structure and summary totals

## Recommended extension path

1. Start with a fixed set of records in `WORKING-STORAGE`.
2. Display one detail line per student.
3. Add pass/fail counters and an average.
4. Move the input to a sequential file once the in-memory version works.

Use the completed projects in `payroll/` and `bank-ledger/` as formatting and structure references.
