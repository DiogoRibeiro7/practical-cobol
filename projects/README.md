# Projects

This directory contains the course capstones. Each project combines several lessons into one realistic COBOL program.

## Start here

If you have just finished the main lesson track, begin with:

1. [`projects/payroll/README.md`](./payroll/README.md)
2. [`projects/bank-ledger/README.md`](./bank-ledger/README.md)

Those two projects are the most complete and best aligned with the current lesson set.

## Project status

| Project | Status | Why it matters |
| ------- | ------ | -------------- |
| `payroll` | complete | end-to-end batch program with arithmetic, conditions, files, and report totals |
| `bank-ledger` | complete | transaction classification with running balance and formatted statement output |
| `student-records` | scaffold | useful next practice target for grades, averages, and reporting |
| `inventory-summary` | scaffold | useful next practice target for stock thresholds and accumulation |

## How to use these projects

- Read the project README first.
- Compare the project structure with the lesson sequence.
- Run the finished projects before modifying them.
- Treat the scaffold projects as guided exercises for independent practice.

The projects are where the repository stops being a list of examples and starts behaving like a small COBOL course.
