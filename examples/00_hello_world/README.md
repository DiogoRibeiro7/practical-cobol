# 00 - Hello world

## Goal

Write and run your first COBOL program.

## What this teaches

- the minimum structure of a COBOL program
- how to print text with `DISPLAY`
- how to end execution with `STOP RUN`

## Code

See [`main.cob`](main.cob).

## Compile and run

```bash
cobc -x -o hello main.cob
./hello
```

## Expected output

See [`expected_output.txt`](expected_output.txt).

## Exercise

Change the message so the program prints your own custom greeting.
