# 01 - Program structure

## Goal

Understand the main divisions of a COBOL program.

## What this teaches

- `IDENTIFICATION DIVISION`
- `DATA DIVISION`
- `WORKING-STORAGE SECTION`
- `PROCEDURE DIVISION`

## Compile and run

```bash
cobc -x -o structure main.cob
./structure
```

## Exercise

Add a second variable and display both values.
