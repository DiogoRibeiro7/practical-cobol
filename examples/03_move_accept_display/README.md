# 03 - MOVE, ACCEPT, and DISPLAY

## Goal

Read input from the user, move values between fields, and display them.

## What this teaches

- `ACCEPT` for keyboard input
- `MOVE` for assignment
- `DISPLAY` for output

## Compile and run

```bash
cobc -x -o io main.cob
./io
```

## Exercise

Read a first name and a last name into separate fields and display them on different lines.
