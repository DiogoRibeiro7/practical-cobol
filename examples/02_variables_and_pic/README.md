# 02 - Variables and PIC

## Goal

Learn how COBOL describes data using the `PIC` clause.

## What this teaches

- alphanumeric variables with `X`
- numeric variables with `9`
- fixed-size field definitions
- displaying stored values

## Compile and run

```bash
cobc -x -o vars main.cob
./vars
```

## Exercise

Add a third variable for a city and display it.
