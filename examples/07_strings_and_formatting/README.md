# 07 - Strings and Formatting

This lesson shows a simple way to build readable output using text fields.

## Goal

Learn how to:

- store names in alphanumeric fields
- combine labels and values in the output
- think about formatting for reports and business messages

## Program idea

The program stores a customer name and a balance, then prints a short account summary.

## Main concepts

- alphanumeric variables with `PIC X(...)`
- numeric display formatting with edited picture clauses
- report-style display lines

## How to run

```bash
cobc -x -o lesson07 main.cob
./lesson07
```
