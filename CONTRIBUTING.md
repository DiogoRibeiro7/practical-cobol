# Contributing

Thank you for contributing to Practical COBOL.

## General principles

Please keep contributions aligned with the teaching goals of the repository:

- Prefer clarity over cleverness.
- Keep examples small and focused.
- Add explanations, not only code.
- Preserve a gradual learning curve.
- Use plain English in lesson notes.

## Lesson structure

When adding a new lesson, follow this structure:

```text
lesson_name/
├─ README.md
├─ main.cob
├─ expected_output.txt
└─ notes.md
```

## Code style

- Keep COBOL examples readable and well indented.
- Use uppercase COBOL keywords for consistency.
- Add comments only when they improve understanding.
- Avoid advanced syntax unless the lesson specifically teaches it.

## Pull requests

A good pull request should:

- explain the teaching purpose of the change
- mention whether it adds a new lesson, exercise, or project
- include documentation changes if new concepts are introduced

## Ideas for contributions

- new beginner exercises
- file-processing examples
- mini projects
- diagrams for COBOL structure
- comparison notes with other languages
- fixes for setup instructions on different platforms
