# Exercises

This directory turns the lesson sequence into a practice track. The exercises are grouped by difficulty so you can move from single-concept drills to small business-style programs.

## How to use this folder

1. Read the matching lesson first.
2. Attempt the exercise without opening the solution.
3. Compare your result with the worked answer in `exercises/solutions/`.
4. Rewrite the solution in your own style so the logic becomes yours.

## Level guide

- `beginner` - one main idea at a time, but still realistic enough to require planning
- `lower-intermediate` - combines two or more lessons in the same program
- `project-prep` - closer to the style of the repository's larger report and batch programs

## Suggested path

- Start with `beginner/` after lessons 02 to 04.
- Move to `lower-intermediate/` after lessons 05 and 06.
- Tackle `project-prep/` after lessons 08 and 09.

The solutions mirror the same level structure under `exercises/solutions/`.
